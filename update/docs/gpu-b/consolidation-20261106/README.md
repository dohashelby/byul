# B 현행 문서 안내

현재 구현·검증 범위, 남은 입력과 담당은 [B 현재 인계](../CURRENT_HANDOFF.md)를 따른다.

종료된 실행·준비 기록과 고정 후보 소스는 [정리 전 불변 Git 이력](https://github.com/dohashelby/byul/tree/451292dbdae4013f9437537c608a1e9f7205b792/update/docs/gpu-b/consolidation-20261106)에 있다. 복원 명령은 현재 인계에 적혀 있다.

기존 결과의 FAIL·UNKNOWN·정확 Ref와 실측/CPU 출처를 보존한다. 현재 인계는 과거 실행 기록의 제품 완료 판정을 바꾸지 않는다.
