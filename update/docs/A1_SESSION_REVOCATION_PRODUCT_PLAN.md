# PLT11 기존 연결·session·handle 철회 경계

공동c9af729·PR127 a76ee693b81799df86324e224a90ab5263dbcd81과 기존 미커밋/worktree/sources/·A2/B 원본·과거팩/Ref·실증을 보존한다. 부모A39/56/4·A1 19/27/2를 유지한다. PLT11/SC19-02의 원팩31 질문/정상·위반·미확인/기존 연결과 신규 접근 비교·다른76개 정의 bytes를 유지한다. PLT10의 다섯 신규 GET은 기존 session 근거가 아니다.

실제 issuer/cache/사건 근거 및 사용 중인 session/handle 종류·코드/설정·잔존 유지/종료 정책은 사용자 질문으로 확인 중이다. 미응답은 정책 승인이나 대상 확정이 아니다. 첫 공개 전송 범위로 고정 GET /v1/models의 HTTP/1.1 keep-alive 연결 식별을 개발한다. 애플리케이션 session·RPC handle·SSE·Gateway·TLS·worker 권한을 대신 증명하지 않는다. 실제 issuer/source/정책이 준비되면 이 범위와 동일한지 검토해 소비한다.

실제 소비자는 명시 DRAFT PLT11의 기존 select/run/judge/report/verify/export/restore·저장팩 정확Ref다. 전송은 control-before → retired-session-open → 같은 연결 retired-session-reuse → 별도 새 retired-new → control-after다. 같은 연결은 명시 connect 뒤 auto_open=0으로 재연결을 금지하고, 매 요청 전후 동일 socket 객체·Linux device/inode와 연결 닫힘 여부로 확인한다. 이 사실은 probe의 TCP 연결이며 serving worker/issuer의 신뢰 producer나 애플리케이션 session receipt가 아니다. source와 native8의 유일 ASGI request/invocation/auth/등록 handler/PID-start-session을 각각 결합한다.

필수 정책은 정확 ENV/target/prepared, aware 유효창/기존 연결 생성 기한/재사용 금지 기한/clock 오차/짧은 준비 대기 상한, 비밀 아닌 issuer/event/선택 역할 라벨과 명시 무조건 제약 또는 실제 사건 기반 기한, 기존 연결의 제한된 처리 방침이다. 정책을 기본값으로 만들지 않는다. 사건 producer/철회 전 정상·신뢰principal/전체 session 범위를 확인할 수 없으면 전체 판정은 UNKNOWN이다. 명시 무조건 기존 연결 재사용 금지 시각 뒤 동일 연결의 정상 수락/등록 handler 반환을 확인한 제약만 functional 독립 FAIL로 기록하며 보안 우회나 실제 철회 전파 완료로 올리지 않는다.

키는 서로 다른 두 환경변수에서 메모리로만 읽는다. 키 원문/hash·Authorization·원문 응답/오류·Pod env/argv를 저장하지 않는다. issuer·자격·Secret·공유 Pod/정책 캐시를 변경하지 않는다. source 고정된 기존 bounded HTTP framing을 재사용하되 기존 stream probe/profile bytes는 수정하지 않는다. 시간/출력·ENV/model mapping·소유 engine/probe·전후 namespace/Pod/container/image/restart/start·lab/image/source gate와 native0.32 미지원은 유지한다.

직접 검증은 소유 로컬 실제 keep-alive 서버에서 같은 연결/재연결·조기 종료·timeout·비정상 body·기한/clock·정리 실패를 구분한다. 제품 회귀는 고정 auth/등록 handler/native8 EXAMPLE와 기존 정식 registry/CLI의 정상·명시 위반·조건부·누락·중복·교체/restart·seal/capture/첨부/정리 후속 오류·정확Ref·비밀 원문/hash 비보존이다. 구현·회귀·문서 종료 뒤 source를 고정하고 영향/Linux/설치본·확정 커밋·초안PR·정확CI·인계를 마감한다. 관측 helper만으로 묶음이나 전체 PLT11을 마감하지 않는다.
