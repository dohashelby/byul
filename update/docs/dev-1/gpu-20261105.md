## 관측과 남은 공백

- REQ-01: 격리 PASS → 소유 시험 NetworkPolicy 열림 FAIL → 복구 PASS.
- REQ-11: 첫 command 미선언 UNKNOWN 보존. 새 세대에서 실제 command·관리 템플릿·모델 mount와 JSON/SSE 8개 사례의 입력 투영·연결 대응을 검증했다. 생성 출력 소유권 독립 증명은 없어 보안 UNKNOWN이다.
- REQ-13: 엔진은 금지 반환 옵션 수용으로 FAIL, Gateway는 3개 모두 400 거부. 실제 응답·오류 허용 필드의 기업 승인값은 만들지 않았다.
- REQ-15: 실제 runtime Gateway의 per_principal HMAC salt·별도 A/B 자격·양 방향 대조. 같은 집단은 hit, 교차 집단은 miss, salt 위조 2건은 4xx다. HTTP 전후 Gateway·엔진 세대를 함께 검증한다. 기업 신원/승인/생산자 진위 인증은 아니다.
- REQ-18: V2 자리 재사용·실제 sampler 상태·단독 출력 대조. REQ-19는 prefix hit로 경계를 못 넘은 첫 UNKNOWN을 보존하고 사례별 salt로 재측정했다. 실제 query31/1020/1054/1060, 호출14·4사례의 범위·padding·GPU 완료·독립 계산을 대조했다. 하드웨어 메모리 검사기는 아니다.
