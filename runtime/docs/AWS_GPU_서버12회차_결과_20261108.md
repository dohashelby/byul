## 종료 상태

- 승인본 4개와 승인 기록은 `/srv/serving/verification/approved`에 유지했다. 폐기 목록 승인본이 없으면 Gateway가 모든 요청을 거부(fail-closed)하기 때문이다.
- Gateway는 `rt-e594df2`와 새 인자로 실행 중인 상태로 중지했다. 비밀 정책 `runtime-tg-secret-01`은 바꾸지 않았다.
- 에이전트 서비스는 시험 전처럼 `disabled`/`inactive`로 되돌렸다. 수집기 서비스 2개와 사용자 수집기 2개는 활성 상태로 유지했다.
- EC2 stopped를 22:20:51 KST에 직접 확인했다(정상 Stop, 강제 중지 없음).

## 확인 범위

- 화면 확인은 Gateway API 응답 값으로 했다. 플랫폼 대시보드 화면을 서버에 연결해 보지는 않았다. 값별 화면 표시는 web 시험(156건)으로 확인했다.
- 외부 집행 상태가 `monitor`/`mixed`로 표시되는 경로는 이번 실서버에서 확인하지 못했다(문제 1 때문). 단위 시험으로만 확인했다.
- 자산 무결성의 변경·누락 탐지는 실제 모델을 바꾸지 않고 단위 시험으로만 확인했다.
- 승인은 LAB 자기 승인이다. 운영 승인 절차와 승인자는 아직 정하지 않았다.
