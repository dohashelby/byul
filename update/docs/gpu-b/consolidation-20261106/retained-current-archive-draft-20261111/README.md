# 현재 case 원자료 Session 연결 초안

과거 GET 반출의 ConnectTimeout 재발을 피하기 위한 미통합 부품이다. [고정 코드 텍스트·영수증](source-manifest.json)과 [한정 검토](focused-review.json)를 보존한다. 실행 모듈이나 실제 driver 경로에 채택하지 않았다.

CPU11/0은 원 pack/select producer→새 binding, checked_file→Recovery 생성자·동일 packet, 거부/예외 객체·remote command 구문 경계다. 실제 driver main/진입점·stream 송수신·receive_bound의 STS/clock/Session/finish·부모 absolute deadline은 실행·통합하지 않았다. 기존 driver의 GET 경로도 아직 바뀌지 않았다. FD는 번호5개가 전후 같은 것이며 FD 객체·inode 동일성을 주장하지 않는다.

현재 descriptor는 UNBOUND/actual=false다. 실제 archive bytes/SHA는 향후 자기 case의 whole/export/discovery가 긍정 확인된 뒤에 발급해야 한다. 원 driver finally의 단일 normalstop과 원 whole 오류를 보존하는 통합이 남는다. 원900/65·24MiB·source guard를 완화하지 않았으며 부모 기한 결합은 미검증이다.

검토된 미통합 초안이라는 범위로만 인계한다. 마감 요청에 따라 새 GPU·추가 실측·staging을 시작하지 않는다. 이미 완료한 원GB12 회수/1971CRC·S3정지와 이 신규 경로의 준비 상태는 별개다. 운영·제품 완료는 false다.

원 freeze의 review-pending 표시는 당시 값이다. [후속 필수 검토 연결](required-component-review-link.json)로 부품 검토 완료를 별도 기록하며 원문을 바꾸지 않는다. 운영 미통합·NOT_READY는 유지한다.
