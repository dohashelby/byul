## 작업 중 문제와 보완 범위

- 묶음 `current` 링크 교체가 권한 문제로 실패한 채 Gateway를 재시작해 이전 묶음을 읽었다. `sudo`로 링크를 교체하고 다시 시작했다. 인수 시험 전이어서 판정 결과에는 영향이 없었다.
- `sudo`로 실행한 preflight의 수집기 서비스 `fail`은 사용자 서비스 조회 범위 때문에 생긴 거짓 결과였다. 일반 사용자 실행에서는 `ok`였다. 첫 실행의 단계 시간표는 `unknown`이었고 이후 재실행은 `ok`였다.
- 관리 키 옵션의 `/proc` cmdline 검사 명령은 검사 프로세스 자신의 인자가 일치해 `True`가 나왔다. 자기 자신을 제외하면 일치 0건이었다. 실행순서표의 검사 명령을 수정했다.
- 서버 실행 뒤 교차 검수에서 도구 수정 4가지를 추가 보완했다: 실제 연결 확인 전 이전 gap을 닫지 않고 backfill 요청, 시간 역전 기록 손상 처리, 증거 가리기 확대, AWS-13 로그 재조회 8초 제한. **이 보완판은 서버에서 다시 실행하지 않았다.** backfill이 실제로 전달됐는지도 확인되지 않았다.
