## 종료 상태

- Tetragon 정책 asset·cache는 monitor 명시 spec으로 교체됐다(이전 객체는 증거에 0600으로 보관). secret은 그대로다. 시험용 sentinel 정책은 그대로 남겼다.
- 감시 baseline은 새 spec으로 다시 캡처했다(이전본 `baseline.json.run14-bak`).
- 묶음은 원래 `bundle-cbb2ce62…`로 되돌렸다. 시험으로 만든 묶음 `bundle-c6fb04ff…`는 서버 묶음 폴더에 남아 있다.
- Gateway는 `rt-f079b2d` + `--gpu-state`로 실행 중인 상태로 중지했다(임시 `--engine-receipts`는 제거).
- 에이전트 서비스는 `disabled`/`inactive`. GPU·Tetragon 상태·모니터 창 서비스는 활성 유지.
- 역방향 터널·port-forward·서버 연결 플랫폼(18710)을 닫았다. 노트북 플랫폼(8700)은 새 코드로 계속 실행 중이다.
- EC2 stopped를 15:49:03 KST에 직접 확인했다.
