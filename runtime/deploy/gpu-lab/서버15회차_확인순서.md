# AWS GPU dev 서버 15회차 확인 순서 (14회차 발견 1~4 조치 확인)

- 코드: Codex 교차 검수·수정 뒤 `byul_runtime` HEAD. Gateway 이미지 `serving-gateway:rt-<HEAD 7자리>`.
- 원칙
  - 사용자 승인 후 기동, 끝나면 Stop 요청 뒤 stopped 직접 확인.
  - 에이전트는 끝까지 `disabled`/`inactive` 유지(필요할 때만 `--once`로 손 실행).
  - 토큰·IP·계정 번호·인스턴스 ID는 문서·증거에 남기지 않는다. 증거 반출 때 0건 검사.
  - 차단 전환·AWS-07 이후 인수 시험은 하지 않는다.
