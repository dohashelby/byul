# OBS02 native19 startup/file context 후보의 제품 연결

A-1은 A-2 PR163 확정715755e4456b26f8e063e9cd2719c35634a12272의 전용3파일 원bytes를 소비한다. 공개 `guard.collectors.native_worker_model_files.analyze(packet, prepared)` 0.1.0, schema `guard-native-startup-file-context-candidates/1`을 기존 `observation_identity:kubernetes` 0.4.0의 explicit native19 분기에 연결한다. native17/18 전용 소비와 기존 profile/source/image/lab/native0.32 경계는 유지한다. B 전용 callback·판정·pin을 대신 보수하지 않는다.

공통 startup/weight/mapping 관측 뒤 전용 분석을 summary `projection.scoped_startup_file_contexts`와 EVD `identity_native_models[].configured_model_candidates[].scoped_startup_file_context_candidates`에 붙인다. 동일 recording/PID/start/model/loader/root와 공통 startup call·point·root/link·시작/종료 seq를 대조한다. startup 종료, root 마지막 seq, mapping 첫/마지막 및 잘린 목록의 untruncated 마지막 locator까지 선택 forward 이전이어야 한다. PID·시간 겹침·같은 경로/opaque model object만으로 귀속하지 않는다.

첨부는 모두 계산한 후 반영한다. 전용 실패는 정제 `NATIVE_WORKER_FILE_CONSUMER_UNAVAILABLE`와 ABORTED로 남기며 앞선 공통 사실·독립 FAIL을 지우지 않는다. 공통 startup 소비가 실패했다면 전용 함수를 재호출하지 않는다. 원문 요청/응답·예외·파일/maps/주소·env/argv를 저장하지 않는다.

선정 검증은 원 A2 분석, 교차 세대/root/startup/마지막 경계 및 원자적 첨부, 기존 OBS02 CLI 정상·callback 실패·후속 기록/첨부·전용/공통 소비 실패·귀속 누락, EVD/RES/RPT·verify·반출/복원·저장팩 정확 Ref다. 직접/동일 계약·인접 회귀·wheel/설치본은 고정 source와 별도 결과로 인계한다. 이 초안은 통과 결과를 미리 선언하지 않는다.

선정 양성 CLI는 원 vLLM 함수 body·EXAMPLE serving/worker/class 의존성과 명시적인 library_identity 시험 대역을 사용한다. A2의 실제8파일 bytes 고정 검사·prepared/packet/profile parser는 바꾸지 않는다. C library 거부 경로는 원 A2 library-unavailable 시험으로 따로 확인한다. 이 대역을 실제 C gate 통과·실제 worker 관측으로 집계하지 않는다.

관측 주체/콜백/프로세스/소스와 승인 주체/모델 허용·정책 효력은 별개다. 함수 이름·반환·mapping·tensor 경계가 실제 worker 역할·준비/READY·GPU·승인·최종 tensor 적용·물리 해제·전체 inventory를 증명하지 않는다. 원 truth=false·security UNKNOWN과 EXAMPLE/DECLARED 의미를 유지한다. PR164 실제 C CPU 원5+alias namespace delta1 근거와 이번 EXAMPLE 제품 입력은 별도이며 실제 C 실행을 native19 worker capture로 소급하지 않는다.

공통 전체 source는 검토 후 A측 literal pin으로 고정한다. B160의 원 승인쌍·c9/helper는 보존하고 새 공통 기준은 B 재검토 전 거부된다. runtime hash 자동 승인·경로 제외·새 skip은 없다. CI5는 정확 HEAD 성공 전 미확인이다. AWS/GPU/Start/IAM·기간/비용 확대는 없으며 부모A39/56/4·A1 19/27/2와 원자료·팩/Ref·과거 실증을 보존한다.
