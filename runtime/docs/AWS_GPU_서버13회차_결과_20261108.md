## 회차 중 고친 버그

| 항목 | 내용 |
| --- | --- |
| 증상 | 네 정책이 기대 spec과 모두 일치해도 external_enforcement가 항상 `unknown` |
| 원인 | Gateway가 `bundle.json`의 `policy_ref.sha256`과 자기가 읽은 `runtime-policy.json` 해시를 비교했다. 그런데 `policy_ref.sha256`은 플랫폼 원본 정책 문서의 해시다. 서로 다른 파일이라 실제 묶음에서는 같을 수 없다(실측 `75cd5222…` 대 `2398bcd7…`). 단위 시험은 두 값이 같은 가짜 묶음을 써서 잡지 못했다 |
| 수정 | `6fc6c30`: policy_id·판본 일치, 그리고 묶음 `files`의 `gateway_policy` sha256과 비교한다. 실제 `bundle_tools`로 만든 묶음으로 monitor/mixed 판정과 파일 해시 불일치 시 `unknown`을 시험한다. runtime 934건 통과 |

## 종료 상태

- 비밀 정책 `runtime-tg-secret-01`은 묶음과 같은 엔진 대상 `monitor`로 남겼다. 이전 시험용 정책은 증거에, 이전 baseline은 서버 `baseline.json.run13-bak`에 보관했다.
- Gateway는 `rt-6fc6c30`으로 실행 중인 상태로 중지했다. 승인본 4개와 공개 Lab 보고서 1개를 유지했다.
- 에이전트 서비스는 `disabled`/`inactive`로 되돌렸다. 수집기 서비스는 활성 상태로 유지했다.
- EC2 stopped를 23:25:58 KST에 직접 확인했다(정상 Stop).

## 확인 범위

- 외부 집행 `enforce` 표시는 이번에 확인하지 않았다(차단 전환을 하지 않음). 단위 시험으로만 확인했다.
- AWS 인수 시험은 AWS-01~06만 실행했다. 상태를 바꾸는 AWS-07 이후 사례는 실행하지 않았다.
- 플랫폼 대시보드 화면을 서버에 연결해 보지는 않았다. API 응답과 계약 검사로 확인했다.
