# 실제 이미지 설치 소스 대조와 M-A3 자격 공백

2026-11-14 사용자 결정31의 로컬 대조 결과다. 엔진·컨테이너·GPU를 실행하지 않았다. 이미지 쌍은 작업지시서0.1절의 고정 digest 그대로다. [정확한 수치·원자료 지문](ma3-image-qualification-20261114.json)을 함께 보관한다.

## 완료한 대조

- 중복 제거48개 레이어의 크기/SHA를 검증했다. 기존 Python 두 레이어661,014,960 bytes를 재사용하고46개·13,630,448,638 bytes를 추가 다운로드했다.
- 모든 레이어 순서·whiteout·이미지 내부 링크를 반영해 설치 소스/메타데이터660,944,108 bytes를 선택 추출했다. 추출2GiB·여유12GiB 하한을 유지했다. 압축 레이어 전체를 풀거나 이미지/엔진을 실행하지 않았다.
- 기준 쪽 선택 파일17,541개·후보 쪽31,346개다. 기준의 공백2개는 OS의 lsb_release.py 링크이며 원 진단을 보존했다. vLLM 관측 대상 경로의 대조를 이 링크로 대신하지 않았다. 후보 추출 공백은0개다.
- 확보된 태그 원본과의 정확 SHA-256/크기 대조는 기준41/41개·후보73/73개가 일치했다. Git blob 대조는 각각574개·2,479개가 일치했다. Git SHA-1 결과는 보조 자료이며 고정값 승인 근거로 대체하지 않는다. 태그 트리에 없는 빌드/제3자 파일3개·202개는 별도 목록으로 남겼다.
- 후보 전용 고정값 표13행과 함수53개는 설치 bytes/코드 지문이 모두 일치했다. 두 쪽 통신 버퍼 파일도 기존 정확 후보 행과 일치했다. 제품의 pin_status·등록표는 변경하지 않았다.

## 실행 자격과 구분할 사실

| 항목 | 기준 판본 | 후보 판본 |
|---|---|---|
| 최종 인터프리터 바이너리의 식별 문자열 | 3.12.8 | 3.12.3 |
| 관측기15개 표에 해당 runtime 키가 있는 수 | 0/15 | 15/15 |
| fault sensor의 MP 원본이 기존 정확 고정값과 같은가 | 아니오 | 아니오 |
| 실제 엔진/인터프리터 기동·GPU 확인·생산자 등록 | 미실행 | 미실행 |

바이너리 문자열과 표 키 존재는 실제 runtime 자격이 아니다. 기준의 패치 판본 자격은 아직 없고, M-B4 보관 결정을 이번 대조로 해제하지 않는다. 후보도 fault sensor의 multiproc_executor 파일이 기존 고정값과 달라 현재 #269 관측 경로를 그대로 기동할 수 없다. 정확 bytes를 실제로 확인했으므로 실패를 예상할 수 있으며 단순 pin 추가나 검사 완화로 통과시키지 않는다.

기준의 설치 라이브러리 메타데이터는 Transformers4.48.1·Uvicorn0.34.0·Safetensors0.5.2, 후보는 Transformers5.17.0·Uvicorn0.53.0·Safetensors0.8.0이다. 해당 설치 파일·관측 의미의 자격과 실제 모델 로드는 별도다.

## 남은 구현과 실행

1. `vllm_fault_sensor.py`의 정확 MP 원본/함수 의미를 두 이미지에 맞는 adapter/profile로 보완한다. 기준 V0와 후보의 구조를 같은 것으로 가정하지 않는다. 관측 코드를 판본마다 복사하거나 기존 고정값/TP1 검사를 넓히지 않는다.
2. `vllm_rank_fault_closure.py`의 인과적 executor 그룹 연결, TP2 장애 탐지·상위 전달·기한, death 새 소유자 복구를 보완한다. 현재 cross_process_group_verified/scope_complete=false와 독립 위반을 보존한다.
3. 직접 시험과 이미지 자격이 준비되면 구체 비용/기동/중지 승인 뒤 단일 노드TP2에서 검증·등록한다. 현재 중지된 단일GPU EC2 두 개를 합쳐 같은 Pod/container의 TP2 증거로 세지 않는다.
4. SUP-08의 단일GPU 설치/모델 로드와 A7 실제 ENV/target 준비는 별도 제한 세션으로 진행할 수 있다. 현재 실제 ENV/target138쪽·최종 입력 사전 점검은 미완료이며 결과null을 유지한다.

## 검증·보관

추출 도구의 whiteout/덮어쓰기·루트 내부 링크·경로 이탈/해시 거부7건, POSIX 경로/링크 거부6건과10만 경로 overlay 대조를 확인했다. 이미지 설치 대조 도구는 엔진을 import하지 않고 bytes/AST/code 객체를 읽었다. source map/검토 행과 runtime/contracts/판정 기준은 바꾸지 않았다. 실제 설치 자료와 로컬 재현 스크립트·완전한 목록은 작업 폴더 및 전용 캐시에 보관하며 위 JSON의 SHA로 묶었다.
