# 시험 전 1차 확정 기준 — 2026-10-25

상태: **시험 전 1차 확정 — 2026-10-25.** 두 지적의 보완과 독립 재검토를 거친 현재 로컬 문서·양식을 프레임워크 담당 사용자의 요청으로 개발·평가 기준선으로 확정했다. 실제 시험·조직 정책 채택·배포 승인은 적용 단계에서 기록한다. 원격 Git·실제 노션 게시 여부는 별도 관리한다.

## 1. 기준선의 범위

정본 01~05, `data/checklist.json`, `data/environment_template.json`, `data/result_template.json`을 기준으로 삼는다. 로컬 공유용 01~07은 설명 자료, 개발 전달 폼은 구현 명세, 엔진별 검토와 평가 기록은 해당 범위의 근거다. 파일별 SHA-256은 [기준선 판본 목록](data/pretest_baseline_20261025.json)에 보존한다. 체크리스트는 8개 기능·36개 요구·77개 CHK·112개 분기를 유지한다.

## 2. 재대조 결과와 최소 보완

| 지적 | 이미 있던 기준 | 이번에 보완한 연결 |
| --- | --- | --- |
| 업데이트 영향평가 인계 | 01 위협 검토, 02 선정 완결성, 04 변경 근거, 05 영향·회귀·보호 유지 시험과 증거 재사용 | [05 §2.3](05_평가와_증거관리.md#update-impact-handoff)에 변경 근거 → 실제 자산·경계·보호 조건의 영향 → 관련 요구·CHK·분기 → 시험·재사용 범위 → 미결 사항·담당을 기록하도록 연결 |
| 결과의 분기 참조 | CHK·판본·분기명·시나리오, 실제 케이스 조건과 원본 보존 | [05 §6.5](05_평가와_증거관리.md#result-record-template)와 결과 양식에 기존 분기의 `apply_when` 원문을 보존. CHK-SUP-008·REQ-018·REQ-020·PLT-008의 같은 이름·SC 분기를 구별 |

## 5. 검증과 남은 범위

- 체크리스트 전체 bytes의 SHA-256은 `7f857208af8071b9934695f32b8753000f0f7b79aa0d47d1bd42945184875ef0`으로 보존됐다. ID·적용 조건·판정·시험 분기가 그대로다.
- 기존 프레임워크 검증, 선택기 회귀 12개, 지도 데이터·JavaScript 함수 검증이 통과했다.
- 112개 분기의 기존 적용 조건을 포함한 참조가 각 CHK 내에서 유일함을 확인했다. 결과 양식과 문서 JSON 예시 4개를 정본과 대조했고 이전 양식 필드·미실행·미확인 상태를 보존했다.
- 이번 검증은 문서·자료·함수 수준이다. 실제 엔진 실행, 계측 가능성, 평가자 판정 일치, 보호 효과와 사용 부담은 적용·시험에서 확인한다.
- 기존 범위 제한, SGLang의 소스 검토 수준과 세션·지속 KV 적용 공백, TensorRT-LLM 미완료 범위는 그대로 유지한다. 조직 정책·승인·측정값은 생성하지 않았다.

## 6. 확정 이후 변경 관리

이번 두 보완과 연결 확인이 완료됐으므로 새 엔진 설명·자동화·논문 실험의 완성을 기다리며 공통 문서를 계속 확대할 필요는 없다. 새 접점을 기존 요구로 표현할 수 없거나, 충분한 증거에도 판정이 모호하거나, 정상·위반의 오판이 재현되거나, 신뢰 가정·근거가 바뀌면 해당 부분을 개정한다. 편의 개선과 수집기 미지원은 개발 과제로 구분한다. 새 판본에서도 과거 결과와 당시 기준을 보존한다.


## 7. 1차 확정 결정과 후속 작업 — 2026-10-25

사용자는 수정본 재검토 결과를 확인한 뒤 “프레임워크는 이대로 1차 확정”하도록 지시했다. 이에 현행 로컬 문서·양식을 시험 전 1차 확정판으로 기록한다. 기준선의 범위와 판본은 §1 및 파일별 해시 목록을 따른다.

- 유지할 기준: 8개 기능·36개 보호 요구·77개 CHK·112개 시험 분기, 기존 적용 조건과 판정 기준.
- 보완 완료: 업데이트 영향평가와 시험 선정의 공통 인계, 적용 조건 원문을 포함한 분기 참조.
- 독립 재검토: 프레임워크 정합성·지도 함수 검사·선택기 회귀 12개 통과. 112개 분기의 유일 대응, 문서 예시/결과 양식 4개, 기존 양식 값 보존 및 당시 기준선 파일 17개의 해시 일치를 확인했다.
- 개발·시험 후속: 실제 입력·영향 검토·선정·실행의 연동, 결과 저장·내보내기·복원, 계측과 증거 확보. 이미 구현된 부분은 기준과 대조해 확인한다.
- 적용 조직의 결정: 환경·정책값·역할 확정, 위험 수용과 배포·재개 승인.

구현 인계는 [개발 전달 폼 §8](개발전달/업데이트검증_폼명세.md#8-시험-전-기준-보완의-구현-인계--2026-10-25)을 따른다. 향후 기준 개정은 §6의 계기에 따라 근거·영향·판본을 남기며, 이 판본과 당시 결과는 보존한다.
