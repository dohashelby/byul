# REQ013 반환 정보 평가 기록

기록일: 2026-10-24 · 고정 점검 ID: **CHK-REQ-013** · gua ID: **REQ-13** · 보호 요구: **5.1 반환 정보 최소 공개** · Q-C02·Q-C11 / SC-21-01.

**평가 결과는 보안 미충족, 선정 정상 기능 충족, 성능 미확인이다.** gua 2차의 `case1-budget127` 한 실행에서 금지 추가 반환 옵션의 효과와 두 대상의 `prompt_text` 합성 system 표식 반환이 기록됐다. 보완·재시험과 실제 사용 승인 결과는 미확인이다. 이 기록은 공개 선별 관측을 프레임워크에 적용한 검토 기록이며 원 보고서의 `official=false`, 정책 `DRAFT` 상태를 유지한다.

기존 충족 기준은 “비허용 문맥·내부 자료가 반환되지 않는다. 팀 참조 구성에서는 prompt 원문·token ID 추가 반환 옵션을 차단한다. 기업에서 자기 입력 사본 반환을 허용하려면 정책을 변경하고 독자·필드별 권한을 확인한다. 정상 생성 결과가 자기 입력을 인용하는 것과 추가 반환 옵션은 구별한다.”이며, 미충족 기준은 “금지 옵션이 살아남거나 비허용 내부·system·자격 표식이 응답에 나타난다.”이다. 이번 실행에 사용된 수집기·판정기의 네 소스 파일은 선별 자료에 기록된 SHA-256과 로컬 보존본이 일치한다. 현재 프레임워크와 원 gua REQ-13 정의의 충족·미충족·미확인 문구도 일치한다.

**보안 미충족:** 원 RES의 FAIL을 보존하고, 금지 입력 사본 반환을 기존 미충족 조건과 대응시킨다. 다른 분기와 원본 검증의 미확인이 이 위반 기록을 지우지 않는다. **정상 기능 충족:** 선정한 네 표본에 한한다. **성능 미확인:** 원자료가 UNKNOWN으로 기록했으며 자원 점유·허용 기준을 임의로 채우지 않는다.

정상 chat 필드도 초안 허용 목록 밖에 있을 수 있다. 참조 예시 정책은 기존 completion 필드를 유지하며 `choices[].message.*` 등을 포함하지 않는다. 따라서 전체 필드 차이를 전부 민감정보 유출이나 삭제 대상으로 취급하지 않고 API·독자별 허용 목록의 적합성 검토로 분리한다. 이 검토를 통해 정상 필드를 정리해도 금지 추가 반환의 독립 위반은 별도 보완·재시험이 필요하다.

프레임워크 담당자가 먼저 판단할 것은 이 자료에서 채택할 판정의 범위와 재시험의 충분성이다. 실제 독자·허용값·예외·운영 사용 결정은 조직의 권한자가 맡고, 통제 구현·재실행·계측은 개발·시험 담당이 맡는다. 구체적인 담당자와 기한은 현재 미정이다.

## 재확인 조건

1. 같은 원결과·EVD·정책·팩 참조를 보존하고 새 실행·환경·정책·수정 판본을 연결한다. 원 실행을 덮어쓰지 않는다.
2. 선정한 engine/Gateway와 chat endpoint에서 return_prompt_text·return_token_ids 등 채택한 금지 옵션을 요청하고 실제 거부·제거 또는 금지 추가 정보의 비반환을 확인한다. 효과 불명 200·인증 실패·5xx만으로 제한 성공을 판정하지 않는다.
3. 합성 표식의 위치·독자를 구분하고 prompt_text 등 추가 반환과 정상 생성 결과의 입력 인용을 나눠 판정한다. 실제 앱 비공개 문맥 보호를 평가하면 일반 호출자가 알 수 없는 앱 삽입 표식을 사용한 범위를 기록한다.
4. 허용 응답·오류 필드는 해당 API와 독자 정책으로 검토하고, 원 policy mismatch와 금지 옵션 효과를 별도 결과로 남긴다. 채택 정책이 바뀌면 새 판본으로 재평가한다.
5. 시험 전후 일반 요청의 정상 기능과 선정한 안전 오류를 확인한다. stream·alias·직통·추가 오류는 실제 적용 시 필요한 분기만 추가하고 비적용에는 근거를 남긴다.
6. 선정 범위의 확인된 위반이 없어지고 필요한 적용 분기·증거·정상 대조가 갖춰졌을 때만 새 범위의 충족을 검토한다. 독립 위반은 미충족, 필수 증거 부족은 미확인을 유지한다.

재확인이 끝나면 새 결과·잔여 미확인·실제 적용 상태를 운영 담당에게 인계한다. 조직의 승인자는 그 결과와 남은 위험을 보고 사용·재개를 결정한다. 현재 기록은 이 후속 결과를 미확인으로 남긴다.
