# 환경·엔진별 지원/미지원/미확인 목록

기준일: 2026-11-04 · 근거: 개발계획서 v1.4 §10.3(필수 산출물), §9.4(엔진별 완료 범위), §9.5(지원 수준), `docs/AWS_GPU_서버2회차_결과_20261104.md`, `deploy/gpu-lab/ACCEPTANCE.md`

이 목록은 **어디까지 실제로 확인했는지**를 나눠 적는다. 구현했다는 것과 실제 환경에서 동작을 확인했다는 것은 다르다. AWS GPU dev 2회차에서 vLLM·SGLang의 AWS-01~19가 각각 최종 통과했으나, 이는 해당 사례의 `report.json` 판정이다. 중간 `unknown`과 서버 뒤 보완 코드의 미재시험을 구분한다. reference 정식 평가는 아직 하지 않았으므로 어떤 항목도 "정식 확인"이 아니다.

## 확인 수준

| 표시 | 뜻 |
| --- | --- |
| **정식** | 계획서 §3.5 정식 환경에서 확인. 현재 해당 항목 없음 |
| **AWS dev** | 1회차 vLLM AWS-01~08 및 2회차 vLLM·SGLang AWS-01~19의 해당 사례 판정. 2회차의 중간 `unknown`·시험 구간 한계와 서버 뒤 코드 미재시험은 결과 문서 참조. 정식 평가가 아님 |
| **CPU vLLM** | 이 PC에서 vLLM CPU v0.29.0 또는 v0.31.0과 Qwen2.5-0.5B-Instruct로 확인(`docs/S3B_실제환경_시험준비.md` §7, 아래 정책 1.2 행 또는 기능별 확인 수준). 정식 S3B가 아님 |
| **로컬 kind** | WSL2 kind(node v1.37.0)에서 실제 Cilium·Hubble·Tetragon으로 확인. 엔진은 시험 전용 가짜 backend |
| **모의·가짜** | 저장소 안 모의 엔진(`mock_engine.py`)·가짜 backend(`fake_backend.py`, vLLM·SGLang 흉내)로 확인한 항목. 실제 엔진 확인 여부는 각 행에서 별도 표시 |
| **합성** | 공식 형식을 흉내 낸 fixture로만 확인. 실제 수집 자료 아님 |
| **미구현** | 코드 없음 |
| **범위 밖** | 계획서 §2.3 제외 항목이거나 별도 승인 필요 |
