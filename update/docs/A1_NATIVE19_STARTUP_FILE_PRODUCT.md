선정 검증은 원 A2 분석, 교차 세대/root/startup/마지막 경계 및 원자적 첨부, 기존 OBS02 CLI 정상·callback 실패·후속 기록/첨부·전용/공통 소비 실패·귀속 누락, EVD/RES/RPT·verify·반출/복원·저장팩 정확 Ref다. 직접/동일 계약·인접 회귀·wheel/설치본은 고정 source와 별도 결과로 인계한다. 이 초안은 통과 결과를 미리 선언하지 않는다.
