# 환경·엔진별 지원/미지원/미확인 목록

기준일: 2026-10-24 · 근거: 개발계획서 v1.4 §10.3(필수 산출물), §9.4(엔진별 완료 범위), §9.5(지원 수준)

이 목록은 **어디까지 실제로 확인했는지**를 나눠 적는다. 구현했다는 것과 실제 환경에서 동작을 확인했다는 것은 다르다. 정식 환경 시험(승인 GPU·Kubernetes 1.36.5·vLLM v0.31.0)은 아직 하지 않았으므로 어떤 항목도 "정식 확인"이 아니다.

## 확인 수준

| 표시 | 뜻 |
| --- | --- |
| **정식** | 계획서 §3.5 정식 환경에서 확인. 현재 해당 항목 없음 |
| **CPU vLLM** | 이 PC에서 vLLM CPU v0.29.0과 Qwen2.5-0.5B-Instruct로 확인(`docs/S3B_실제환경_시험준비.md` §7). 정식 S3B가 아님 |
| **로컬 kind** | WSL2 kind(node v1.37.0)에서 실제 Cilium·Hubble·Tetragon으로 확인. 엔진은 시험 전용 가짜 backend |
| **모의·가짜** | 저장소 안 모의 엔진(`mock_engine.py`)·가짜 backend(`fake_backend.py`, vLLM·SGLang 흉내)로만 확인 |
| **합성** | 공식 형식을 흉내 낸 fixture로만 확인. 실제 수집 자료 아님 |
| **미구현** | 코드 없음 |
| **범위 밖** | 계획서 §2.3 제외 항목이거나 별도 승인 필요 |

## 갱신 방법

기능이나 확인 수준이 바뀌면 이 표를 함께 고친다. "구현"과 "확인"을 섞지 않고, 확인한 환경을 표시한다. 정식 환경에서 확인하기 전에는 **정식** 표시를 쓰지 않는다.
