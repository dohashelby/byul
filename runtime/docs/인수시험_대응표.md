# 런타임 인수시험 대응표

개발계획서 v1.4 §9.2의 26개와 §9.6의 20개, 총 46개 `RT-*` ID를 현재 저장소의 실행 가능한 근거에 연결한 표다. 근거는 `runtime/tests/test_*.py`, `runtime/src/serving_runtime/mvp/acceptance.py`, `runtime/tools/k8s_lab_check.py`, `runtime/tools/s3b_cpu_precheck.py`에서 찾았다. kind와 CPU 실행 사실은 `runtime/project-context/STATUS.md` 및 `runtime/docs/S3B_실제환경_시험준비.md`의 기록만 반영했다.

상태는 **현재 가장 직접적인 근거의 수준**이다. `kind LAB 확인`은 로컬 kind/WSL과 시험용 backend, `CPU 사전 점검`은 승인 GPU 환경이 아닌 vLLM CPU 결과다. 어느 행도 정식 환경 통과로 표시하지 않는다. 단위 시험이 있어도 RT 행의 모든 완료 기준을 충족한다는 뜻은 아니다.
