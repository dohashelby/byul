새 schema/기업 승인값은 여기서 확정하지 않는다. 각 항목의 구현 담당이 **공식 지원 버전·source commit·실제 producer 경계·소비 함수·실제 producer→consumer 계약 시험과 남은 제한**을 반환해야 한다. S1은 공통 파일을 수정하지 않는다.

1. **SUP09/11 model-entry**: `update/src/guard/executors/dynamic_code_cpu.py::{fixtures,identity,clean_phases,project}` 및 `supply_boot_contract.py::_dynamic/evaluate_record`. 기존 autoconfig/vllm-config·12 case·import/constructor와 독립 FAIL을 유지하고 실제 선택 model class/source bytes·trust·mode·constructor/forward·정상 대조를 구분하는 지원 계약이 필요하다. 재현 자료는 기존 `prepare/SUP09-model-code/v1/handoff.md`와 actual component packets. 검증은 원 loader/model이 만든 실제 record를 원/새 consumer에 각각 넣어 구분·누락·후속 오류·기존 FAIL 보존을 확인한다. 실제 forward event를 기존 import로 이름만 바꾸면 안 된다.
