## LAB 연결·검증 한계

- 서버의 systemd 서비스와 사용자 수집기는 자동 시작했다. 노트북을 플랫폼으로 사용하는 LAB 구성의 임시 SSH 역방향 HTTPS 터널은 재부팅 후 시험기가 다시 연결했다. 터널까지 자동 복구됐다고 판정하지 않는다. 기존 TLS 검증·CA·운영 권한·안전 조건을 완화하지 않았다.
- 기존 서버의 재설치와 재부팅 시험이다. 새 호스트의 계정 최초 생성·baseline 최초 캡처·BPF LSM 부팅 설정 변경·GRUB 최초 설치는 이번에 실행하지 않았다.
- 안전 조건의 운영 기본 모니터 기간을 낮추거나 실제 차단 모드를 바꾸지 않았다. 새로운 파일 읽기 거부·엔진 본체 종료·다중 노드 시험은 이 회차 범위가 아니다.
- 이번에는 기능 코드를 변경하지 않았다. b2d5dd7 통합 전 runtime 881건(skip 0)·API 259건·web 143건 및 타입 검사를 통과했고, 이 회차에서는 실제 호스트 시험과 증거 검증을 수행했다.
