# AWS GPU dev 서버 14회차 확인 순서 (10~14번 + A·B·C·F)

- 코드: `byul_runtime` 로컬 커밋 `66307d6`~`f079b2d`(10~14번 + GPU 패널 수정). 서버에는 git bundle로 옮겨 detached checkout한다.
- Gateway 이미지: `serving-gateway:rt-<HEAD 7자리>`.
- 원칙
  - 서버는 사용자 승인 후 켠다. 끝나면 Stop을 요청하고 stopped를 직접 확인한다.
  - 에이전트 서비스는 끝나면 `disabled`/`inactive`로 되돌린다.
  - 토큰·IP·계정 번호·인스턴스 ID는 문서와 증거에 남기지 않는다. 증거를 반출할 때 0건인지 검사한다.
  - `unknown`이 나오면 자동으로 다시 실행하지 않는다. 실제 객체·모드·Gateway를 먼저 확인한다.
  - 상태를 바꾸는 AWS-07 이후 인수 시험은 이번에도 하지 않는다.

| # | 할 일 | 기대 |
| --- | --- | --- |
| 4-1 | 동기화 전 Gateway 외부 집행 상태 기록 | `unknown` 또는 불일치(예상) |
| 4-2 | runtime-agent kubeconfig 권한 `can-i`(TracingPolicyNamespaced·CNP get/list/create/update/patch/delete, CRD get, tetragon pods/exec) | 부족하면 4-3 전에 기록하고 멈춤 |
