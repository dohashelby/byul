# 결정 기록: LAB 정책 묶음 수신

- 날짜: 2026-10-26
- 범위: LAB, runtime 측 결정

## 결정

- 수신 형태는 같은 호스트의 관리 디렉터리 `DIR`이며, `DIR/bundle.json`과 그 목록의 상대경로 파일로 구성한다.
- platform은 묶음 디렉터리를 원자적으로 완성한 뒤 runtime을 `--policy-bundle DIR`로 시작하거나 재시작한다. runtime은 시작 때 한 번 읽어 검증한 바이트를 프로세스 전용 시작 스냅샷으로 고정하며, 실행 중 관리 디렉터리를 다시 읽어 교체하지 않는다.
- runtime은 bundle 구조, 경로 탈출·역슬래시·심볼릭 링크 탈출, 파일 bytes·SHA-256, 내부 `schema_version`, 번들 유효 기간, gateway policy의 `target_id`와 `target_ref` 일치를 검사한다.
- bundle의 `approval`은 자기신고 기록일 뿐 승인 증거로 신뢰하지 않는다. 승인은 `policy_approvals` 역할 파일을 기존 LAB 승인 검증 방식으로 별도 확인한다.
- 현재 실행 조건 때문에 적용할 수 없는 역할도 검증 목록과 `applied: false` 상태에 남긴다.

## 미결

- 원격 전달 채널
- hot reload
- 관리 디렉터리를 쓰는 주체와 소유권·권한(D-03)

platform은 생산자로서 이 디렉터리 배치·원자적 교체 방식과 파일 권한에 합의해야 한다. 이 기록만으로 platform 측 합의가 완료된 것은 아니다.
