# REQ-17 분할 수집·원 표본 집계 계약

2026-11-14 사용자 결정23으로 승인했다. 기존 최소 표본200개·AUC 기준55·단일 묶음512개 상한과 기존 단일 입력 형식을 유지한다. 실제 GPU 실행·비용·새 입력의 GPU 자격은 별도다.

## 입력

새 그룹 형식은 `byul-engine-callback-cohort-group/1`이다. 그룹 manifest는 session·environment_ref·target_sha256과 정확히 두 개의 parts를 담는다. 각 parts 항목은 index(1 또는2)·고정 상대 파일 이름(part-1.json/part-2.json)·파일 bytes SHA·정규 manifest SHA를 결합한다. 각 파일은 기존 cohort 형식의 cases504개(네 역할100개씩+prime104개)와 같은 세션·ENV/target을 담는다. 각 묶음은 기존 validate_cases의512개 검사를 통과해야 한다. 점수 사례의 중복·다른 세션/ENV/target·추가 묶음·경로 이탈·심볼릭 링크·읽기 중 변조를 거부한다.

기존 단일 manifest의256KiB 읽기 제한은 유지한다. 새 그룹의 작은 manifest도 같은 제한을 받는다. 새 형식의 참조 파일만 각1MiB로 제한해 읽는다. 이 한도는 기존 단일 입력 경로에 적용하지 않는다. 새 파일은 기존 출력과 분리하며 덮어쓰지 않는다.

## 수집과 귀속

각 묶음은 기존 수집 경로를 사용하고 각300초 이하의 기존 설정을 받는다. 두 묶음 설정 예산 합계는 최대600초이며 실제 소요 시간이나 지출을 뜻하지 않는다. 각 묶음504개와 경계 요청1개로 한쪽1,010요청·양쪽2,020요청이다. 실제 비용은 대상과 최신 요금으로 다시 산정하고 별도 승인을 받는다.

관측 소스·정책·ENV/target·prepared·그룹 해시와 실제 Pod/컨테이너 binding을 결합한다. native 행은 기존 qualification·HMAC 요청 귀속으로 고른다. 두 묶음에서 같은 관측 프로세스 세대인지 확인하고, 수집 시간창의 순서·자료 출처 일치를 확인한다. 기준/후보 표본은 합치지 않는다. GPU 등록표·고정값 검사를 바꾸거나 자동 등록하지 않는다.

각 묶음의 engine-sensor.json 안 timing_samples가 `guard-cache-timing-part/1` 원 표본을 보존한다. 표본에는 원 case ID·역할·요청 HMAC 지문·지연 ms(미확인은null)·프로브 시계 필드와 시간 기준·자격 확인된 native 적중 토큰 수만 기록한다. 지연값은 원 시계로 다시 계산해 일치 여부를 검사한다. 프롬프트·출력·토큰 원문·HMAC 비밀을 담지 않는다. 정규 bytes 해시로 수집 직후 확정한 자료와 최종 그룹 참조를 결합한다. 내용 해시는 생산자 인증이 아니며 producer_authenticated=false다.

## 집계

그룹 안에서는 묶음 번호와 원 case ID를 함께 사용한다. 요청 지문 중복·표본 누락·정책/대상/세대 불일치·시간창 중첩·다른 출처·유효하지 않은 지연값을 정상 관측으로 취급하지 않는다. 원 표본을 기존 project_cache_timing에 전달하며 AUC 평균으로 대체하지 않는다. 각 역할의 최소200개와 기존 정상 대조·native hit 조건을 그대로 검사한다.

단독 묶음의100개 표본을200개로 간주하거나 기존 UNKNOWN을 수정하지 않는다. 유효한 개별 위반 또는 완전한 원 표본에서 확인한 위반은 뒤늦은 회수·아티팩트 오류가 있어도 유지한다. 전체 범위·실행 완료·MEASURED 자격은 별도로 낮춘다. 자원 회수나 아티팩트 기록이 미확인인 경우 다음 묶음을 시작하지 않는다.

## 준비 명령

`uv run python -m tools.gpu_a_req17_cohort --seed 26111401 --split --out <새-사례-폴더>`로 후보 사례를 만든다. 실제 ENV/target과 prepared를 확보한 뒤 기존 gpu_a_run_inputs check의 `--check REQ-17 --cases <새-사례-폴더>/group.json`으로 결합한다. 이 명령은 입력 파일만 만들며 엔진을 기동하지 않는다. M-A7 준비 도구도 양쪽에 같은 사례 두 묶음을 연결한다. 실제 ENV/target·노드 설치/자격·정상 요청 사전 점검은 별도다.
