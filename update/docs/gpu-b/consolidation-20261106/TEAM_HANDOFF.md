# GPU 담당 43개 — 1단계 마감 검토와 팀 인계

이 문서는 1단계 작업지시서 기준의 마감 제안과 실제 관측 결과를 함께 검토하기 위한 인계다. 제품 성공, 모든 적용 분기의 실측 완료, 기업 승인과 구분한다. 정확한 원자료 참조는 [기존 색인](evidence-index.json)을 재사용한다.

## 팀원이 먼저 확인할 내용

- 담당 범위는 43ID다. 담당 분류는 GPU 대상33·CPU 대상10이며 실제 실행 환경과 다르다.
- 제품 실행 경로 근거는 25ID다. GPU 환경14·CPU 환경11이며 부분 실행·중단도 포함한다.
- 구성요소·준비·진단 원자료가 있는 추가13ID와 과거 보고만 확인된5ID가 있다. 직접 자료 가용성38은 완료38을 뜻하지 않는다.
- 원질문의 모든 분기를 확인한 ID는0이다. 적용 분기 전체 열거와 분기별 완료 수는 미확정이다.
- 기존 대화의 “42개 마감 가능·SUP-16 1개”는 진행 중 운영 건을 제외한 잠정 행정 해석이었다. 모든 ID의 제품 증거 절차가 끝났다는 확정값으로 사용하지 않는다.

재대조에서는 선정 실행·UNKNOWN 인계에 한정한 마감 제안 검토 대상25ID, 제품 증거 절차가 확인되지 않은17ID, 현재 건 운영 마감과 새 검증을 연결할 SUP-16 1ID로 구분한다. 25ID도 모두 실측 통과 또는 전체 분기 완료라는 뜻은 아니다. 기존 요약의 복원·재판정 보고에 의존하는 범위도 별도로 남긴다.

## 마감 판정 방법

43ID별 한정 판정·부족 근거·담당·재개 입력은 [PHASE1_REVIEW.md](PHASE1_REVIEW.md)에 정리했다. 세션4의 고정 인계 원문을 재사용했으며 이후 SUP-16 운영 결과는 아래 시각이 명시된 추가 인계로 구분한다. LIF-03/05/09, OBS-03, PLT-06/08의 복원·재판정은 기존 요약의 완료 보고를 재사용한 강도임을 보존한다.

지시서3절은 선정→factory→EVD→RES→RPT→반출→복원→저장 팩 재판정을 확인하도록 한다. 5절은 미측정 분기를 원인과 함께 UNKNOWN으로 남긴 종료, GPU 실행 묶음 준비 완료, 기업 입력 대기를 허용한다. 두 기준을 함께 검토한다.

각 ID에는 실제 확인 범위, 원판정·원자료의 확인 범위, 미측정 사유, 다음 담당과 필요한 입력을 남긴다. 제품 증거 절차 미확인·원본 부재·준비 실패를 성공으로 채우지 않는다. 공통 코드 또는 정책·TP2 입력에 막힌 분기는 그 사실을 인계한다. 해당 인계는 새로운 실측을 뜻하지 않는다.

## 현재 건의 마감

SUP-16의 원 실험과 후속 회수용 부팅을 구분한다. 정상 응답·native 파일 읽기 후보와 writer/전체소비/제품 결과의 확인 범위도 분리한다. 정확 GB09 회수·무결성·실행 신원·실제 기록기 출력은 그 원자료와 해당 검증 결과에서 확인된 범위만 기재한다.

원 전송 timeout, 원 stop 감시 실패, 부분 파일, 미반출 자료는 보존한다. 정상 stop 요청 수락과 실제 stopped 관측은 별도 사건이다. 비용 추정과 실제 청구를 구분한다. 현재 원자료 및 운영 종료의 최종 인계가 확인되기 전에는 이 문서만으로 SUP-16을 종료로 승격하지 않는다.

2026-11-06 21:19:40~21:19:43 KST의 후속 조회에서 소유3대 stopped·공인IP0이 확인됐다. 원 회수는900초 timeout, 원 정상stop1회의180초 감시는 실패했고 감독은exit1이었다. 원GB09 전체는 미반출이며 사전 할당된 로컬 partial의 파일 크기를 완성본 증거로 사용하지 않는다. 이번 회수용 부팅에서 모델을 새로 실증하지 않았다.

운영 장부의 보수 추정은 $52.6858739149404이며 실청구액은 미확정이다. 해당 관측까지 compute/IP 구간은 닫혔고, 보존 저장소 비용은 계속된다. 운영 담당은 실행 작업0건으로 정리했으며 최종 control·정리·비용 검증의 연결을 별도 확인한다. 전송 복구가 완전히 해결됐다고 주장하지 않는다.
